# WEB-005C — Public Domain Taxonomy Parity

**State:** READY_FOR_CTO_APPROVAL — DO NOT START
**Scope:** public website IA/copy consistency only
**Blocked by:** WEB-005B / MER-109 terminal visual acceptance
**Blocks:** WEB-006 public launch

## Outcome

Make public route/domain naming consistent with the Product-approved website taxonomy without reopening homepage design.

Canonical public taxonomy:
- Geothermal
- Mining
- Marine

## Problem

The accepted homepage now uses Geothermal / Mining / Marine, while the existing Solutions surface still exposes legacy/application-ledger labels such as Mineral Exploration and Environmental & Land Intelligence.

A visitor should not encounter contradictory top-level domain naming across the public site.

## Required decision/implementation

After WEB-005B is terminally accepted:
- inventory public navigation, Solutions landing content, route labels, anchors and headings that expose domain taxonomy;
- converge visible public IA on Geothermal / Mining / Marine;
- preserve truthful availability/status (Mining/Marine may remain in development);
- do not invent capabilities, customers, claims or scientific scope;
- keep route compatibility where practical through redirects/legacy anchors if needed;
- avoid breaking external/internal deep links;
- do not change scientific semantics or analytical behavior.

## Out of scope

- homepage visual redesign;
- new solution-page visual design beyond minimal taxonomy consistency;
- scientific methodology;
- new product claims;
- WEB-006 deployment/DNS.

## Acceptance

- top-level public navigation and Solutions surfaces use consistent domain names;
- no broken nav/deep links caused by the rename;
- EN/TR remain semantically aligned;
- existing route tests pass;
- no unrelated route redesign.

**Terminal:** REVIEW_READY.
